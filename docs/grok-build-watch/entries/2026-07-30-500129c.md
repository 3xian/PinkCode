### Notes

**Subagent topology (important)**

`[subagents] max_depth` is now resolved from environment, TOML, or remote settings. The default remains one level, but PinkCode currently hard-codes that limit in its TypeScript model and renders a flat parent-to-child strip. A non-default Grok configuration can therefore produce deeper lifecycle events than the UI contract describes.

**Session and task lifecycle**

Closing a session now cancels its subagents and reaps commands, LSP servers, MCP children, hooks, and inherited process scopes. Workspace task snapshots only contain incomplete background work. PinkCode's live task strip and refresh logic should be checked for correct removal rather than relying on completed rows remaining in snapshots.

**ACP / shell behavior**

File-backed plan exit is forced to the tail of mixed tool batches. `/loop` now describes the configured detached/in-session fire mode and teaches stop conditions. Auth-provider commands use the platform shell, fixing Windows behavior. These are implemented inside Grok Build and do not require PinkCode protocol changes.

**Mostly TUI, service, or internal**

Minimal scrollback, terminal probes, privacy/tier surfaces, dashboard docs, telemetry, access gating, thread caps, credential handling, search-cache recovery, workspace git operations, and tool-description corrections are upstream-owned.
