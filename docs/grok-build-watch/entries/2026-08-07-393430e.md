### Notes

**ACP session surface (important)**

Upstream adds first-class `session/list`, `session/resume`, and `session/close`. Changelog: clients can reattach to a running session without replaying the transcript and explicitly close sessions. PinkCode today drives `session/new`, `session/load`, and `session/cancel` only. `session/close` is the clean teardown path vs process drop; `session/resume` is the attach-without-full-replay path vs always `session/load`.

**Stop / cancel + subagents**

User stop now cancels all session subagents (not only the current turn). Esc/`[stop]` suppress task wakes like Ctrl+C. `kill_task` reports missing ACP tasks honestly; blocking wait on an already-completed ACP task returns immediately. Compaction carries running background tasks and subagents. Workflow live subagents are capped (commit note: 16/run; host default concurrent budget 32). PinkCode’s lifecycle strip should keep settling under bulk cancel and mid-compaction survival.

**Commands / skills / tools over ACP**

Chat product Skills are exposed via `available_commands_update` (PinkCode already catalogs that notification). Colliding skills stay invocable beside builtins. Tools can advertise read-only; Voice/Finance get typed `ToolUsageCard` variants. MCP images are extracted before output truncation (large screenshot tool results less likely to corrupt).

**Mostly TUI, auth, leader, or internal**

Dashboard summaries/delete/rename, project-directory picker removal, plan Mermaid buttons, free-form always-allow patterns, rust-toolchain 1.93.0, `GROK_EXTRA_CA_BUNDLE`, session search unlock across many instances, leader version mismatch scrollback, external-auth refresh/sign-in, pager/theme/tmux/Doctor, sandbox provision types, and headless streaming-json are upstream-owned.
