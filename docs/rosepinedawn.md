# Rosé Pine Dawn Palette

Rosé Pine Dawn is the light variant of Rosé Pine and contains 15 colour roles. The table below records HEX values only. Usage descriptions are based on the official Rosé Pine documentation for each colour role.

| Colour role | HEX CODE | Usage |
| --- | --- | --- |
| [Base](https://rosepinetheme.com/palette/base) | `#faf4ed` | Primary background; editor or document background; main application panels such as sidebars and file trees; the colour against which semi-transparent elements are composited. |
| [Surface](https://rosepinetheme.com/palette/surface) | `#fffaf3` | Secondary background atop Base; floating panels such as popups, autocomplete menus, and notifications; input fields such as search bars and command palettes; status bars and title bars. |
| [Overlay](https://rosepinetheme.com/palette/overlay) | `#f2e9e1` | Tertiary background atop Surface; active or hovered list items, tabs, and sidebar entries; visual selection highlights; search match backgrounds; elevated surfaces such as tooltips and dialogs; terminal black. |
| [Muted](https://rosepinetheme.com/palette/muted) | `#9893a5` | Low-contrast foreground; comments and documentation prose; line numbers and scrollbar miscellanea; non-text characters such as whitespace markers and delimiters; disabled or dimmed UI labels; terminal bright black. |
| [Subtle](https://rosepinetheme.com/palette/subtle) | `#797593` | Medium-contrast foreground; secondary text such as labels, tab titles, and breadcrumbs; placeholder text in inputs; inactive or unfocused pane foreground; punctuation and operators. |
| [Text](https://rosepinetheme.com/palette/text) | `#575279` | High-contrast foreground; body text, variable names, and identifiers; active tab or item foreground; cursor colour paired with a Highlight High background; selection foreground paired with a Highlight Med background; terminal white and bright white. |
| [Love](https://rosepinetheme.com/palette/love) | `#b4637a` | Errors and destructive actions; deletions or removed content such as Git diffs; terminal red and bright red. |
| [Gold](https://rosepinetheme.com/palette/gold) | `#ea9d34` | Warnings and caution highlights; string literals; search or match highlights paired with Base; terminal yellow and bright yellow. |
| [Rose](https://rosepinetheme.com/palette/rose) | `#d7827e` | Function calls, method names, and built-ins; modified content such as Git diffs; terminal cyan and bright cyan. |
| [Pine](https://rosepinetheme.com/palette/pine) | `#286983` | Keywords, statements, and control flow; added content such as Git diffs; constructive or affirmative signals; terminal green and bright green. |
| [Foam](https://rosepinetheme.com/palette/foam) | `#56949f` | Informational signals; type annotations and language types; tag names such as HTML and XML; terminal blue and bright blue. |
| [Iris](https://rosepinetheme.com/palette/iris) | `#907aa9` | Hints and suggestions; special characters and escape sequences; attribute names and properties; fuzzy or search match highlights; changed content such as Git diffs; terminal magenta and bright magenta. |
| [Highlight Low](https://rosepinetheme.com/palette/highlight-low) | `#f4ede8` | Low-contrast highlight; cursor line or current line background; subtle row striping in lists and tables. |
| [Highlight Med](https://rosepinetheme.com/palette/highlight-med) | `#dfdad9` | Medium-contrast highlight; text selection background; active or hovered popup menu item background. |
| [Highlight High](https://rosepinetheme.com/palette/highlight-high) | `#cecacd` | High-contrast highlight; borders, visual dividers, and separators; cursor background; search or incremental search match background. |

Source: [Rosé Pine Palette](https://rosepinetheme.com/palette/)
